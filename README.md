# Independent Devil’s Tear guide

Indonesian visitor information for Devil’s Tear / Devil’s Tears (Pantai Batu Belek), Nusa Lembongan, Klungkung, Bali. This is not an operator, government, booking or ticketing site.

## Local workflow

Use Node 24.19 or later and pnpm 11.22.0. Install with `pnpm install --frozen-lockfile`, then run `pnpm check` and `pnpm build`. `astro.config.mjs` sets the production origin and trailing slash convention. The ASSETS Worker enforces HTTPS/apex redirects and preserves missing-page 404 status with noindex. The verified Worker name is `devilstearsbali`.

## Sources

Public sources and photo credits are linked on the visitor page. The dated Maps 24-hour listing is not a guarantee of night access. District levy categories must not be represented as a universal single-attraction ticket. Old facility plans and safety inspections do not establish current availability or safety.

Optional analytics requires explicit consent. A session refusal takes priority over an old permanent choice when a permanent preference write fails. No contact, account, booking, marketing or separate preference feature is provided. Embedded Google Maps is disclosed separately.

Generated assets are included for review and must be rebuilt together with source changes. Local code, artifact and HTTP checks do not establish production visual acceptance.
